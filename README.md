# たんごちょう

健太・かつにいのための単語帳＆出題アプリです。フロントエンドのみで完結し、データはブラウザの localStorage に保存されます。

## 機能

1. **ユーザー選択画面（トップページ）**
   - 「健太」「かつにい」の2つの選択肢を表示し、それぞれ専用の単語帳ページへ遷移します。
2. **単語帳ページ（個人ごと）**
   - 登録した単語・例文の一覧を表示します。
   - 「単語/文」+「意味」の新規登録フォームがあります。
   - 一覧から編集・削除ができます。
3. **出題モード**
   - 出題元を「健太の単語帳」「かつにいの単語帳」から選択できます。
   - 出題形式（単語→意味 / 意味→単語 / ランダム）を選べます。
   - 3択クイズ形式で、正解・不正解のアニメーション演出があります。

## セットアップ

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

`dist/` に静的ファイルが出力されるので、そのまま任意の静的ホスティングで公開できます。

## 技術スタック

- React 18 + Vite
- react-router-dom（HashRouter）
- Framer Motion（アニメーション）
- localStorage（データ永続化、サーバー不要）
